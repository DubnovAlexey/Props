Почти все ошибки с пропсами сводятся к трём причинам: передали не тот тип, изменили чужие данные или спутали ссылку с вызовом. Каждая ошибка ниже воспроизведена запуском на React 19.3.1, а тексты сообщений взяты из консоли.

### Сводная таблица

| № | Ошибка | Симптом | Раздел |
| --- | --- | --- | --- |
| 1 | Число в кавычках: `quantity="2"` | `quantity + 1` даёт `"21"` | 3 |
| 2 | Забыли `{ }` в параметрах: `function Card(name)` | «Objects are not valid as a React child» | 4 |
| 3 | Присвоили пропу: `props.quantity = 1` | «Cannot assign to read only property»; в продакшене молча | 5 |
| 4 | Изменили объект из пропсов: `product.quantity -= 1` | Ошибки нет, но данные родителя испорчены | 5 |
| 5 | Вызвали функцию вместо передачи: `onClick={onDelete(id)}` | Удаление без клика и «Cannot update a component while rendering a different component» | 7 |
| 6 | Скопировали проп в состояние: `useState(quantity)` | Новое значение от родителя не показывается | 6 |
| 7 | Индекс в роли key в изменяемом списке | Состояние «переезжает» к соседнему элементу | 9 |
| 8 | Читаем `props.key` внутри компонента | `undefined` и «`key` is not a prop» | 2, 9 |
| 9 | `{quantity && …}` при нуле | На экране появляется «0» | 13 |
| 10 | `class` и `for` вместо `className` и `htmlFor` | «Invalid DOM property `class`. Did you mean `className`?» | 9 |
| 11 | Свой проп ушёл в HTML-тег через `{...rest}` | «React does not recognize the `isActive` prop on a DOM element» | 9 |
| 12 | Имя компонента с маленькой буквы: `<productCard />` | В DOM появляется пустой тег `<productcard>` | 2 |
| 13 | `defaultProps` у функционального компонента | В React 19 значение не подставляется | 4, 11 |
| 14 | Новые объекты и функции в пропсах memo-компонента | `memo` не срабатывает | 10 |
| 15 | `value` без `onChange` | Поле только для чтения и предупреждение в консоли | 13 |

### 1. Число в кавычках

```jsx
<ProductCard quantity="2" />  // НЕПРАВИЛЬНО: придёт строка '2'
<ProductCard quantity={2} />  // ПРАВИЛЬНО: придёт число 2
```

### 2. Забыли фигурные скобки деструктуризации

```jsx
function ProductCard(name) { return <h3>{name}</h3>; }    // НЕПРАВИЛЬНО: name — это весь объект props
function ProductCard({ name }) { return <h3>{name}</h3>; }  // ПРАВИЛЬНО
```

### 3–4. Изменение пропсов и объектов из них

```jsx
// НЕПРАВИЛЬНО: ребёнок меняет чужие данные
function ProductCard({ product }) {
  product.quantity -= 1;
  return <p>{product.quantity}</p>;
}

// ПРАВИЛЬНО: ребёнок просит, родитель создаёт новый объект
function ProductCard({ product, onEat }) {
  return <button onClick={() => onEat(product.id)}>Съесть одну</button>;
}
// в родителе: setProducts(products.map((p) => p.id === id ? { ...p, quantity: p.quantity - 1 } : p))
```

### 5. Вызов вместо передачи

```jsx
<button onClick={onDelete(product.id)}>Удалить</button>       // НЕПРАВИЛЬНО: сработает при рендере
<button onClick={() => onDelete(product.id)}>Удалить</button> // ПРАВИЛЬНО: сработает по клику
<button onClick={onDelete}>Удалить</button>                  // тоже правильно, если аргумент не нужен
```

### 6. Копирование пропа в состояние

```jsx
function ProductCard({ quantity }) {
  const [qty] = useState(quantity); // НЕПРАВИЛЬНО: запомнит только первое значение
  return <p>{qty}</p>;
}

function ProductCard({ quantity }) {
  return <p>{quantity}</p>;        // ПРАВИЛЬНО: читаем проп напрямую
}
```

### 7–8. Ключи списка

```jsx
{products.map((p, i) => <ProductRow key={i} product={p} />)}    // НЕПРАВИЛЬНО, если список меняется
{products.map((p) => <ProductRow key={p.id} product={p} />)}    // ПРАВИЛЬНО

<ProductRow key={p.id} productId={p.id} product={p} />           // id нужен внутри — отдельным пропом
```

### 9. Ноль с оператором &&

```jsx
{product.quantity && <span>{product.quantity} шт.</span>}     // НЕПРАВИЛЬНО: при 0 выведет «0»
{product.quantity > 0 && <span>{product.quantity} шт.</span>} // ПРАВИЛЬНО
```

### 10–12. Имена: атрибуты HTML и компоненты

```jsx
<label class="label" for="dish">Блюдо</label>          // НЕПРАВИЛЬНО: работает, но с предупреждениями
<label className="label" htmlFor="dish">Блюдо</label>  // ПРАВИЛЬНО

function Card({ isActive, ...rest }) {                 // ПРАВИЛЬНО: свой проп забрали до spread
  return <div className={isActive ? 'card active' : 'card'} {...rest} />;
}

<productCard />  // НЕПРАВИЛЬНО: React считает это HTML-тегом
<ProductCard />  // ПРАВИЛЬНО
```

На `<productCard />` React выдал два предупреждения. Первое: «is using incorrect casing. Use PascalCase for React components». Второе: «If you meant to render a React component, start its name with an uppercase letter». **PascalCase** — запись, в которой каждое слово, включая первое, начинается с большой буквы: `ProductCard`.

### 13. defaultProps в React 19

```jsx
function Badge({ size }) { /* ... */ }
Badge.defaultProps = { size: 100 };       // НЕПРАВИЛЬНО: в React 19 игнорируется

function Badge({ size = 100 }) { /* ... */ } // ПРАВИЛЬНО
```

### 14. memo и новые ссылки

```jsx
<MemoCard product={{ ...p }} onDelete={() => remove(p.id)} /> // НЕПРАВИЛЬНО: всё новое каждый рендер
<MemoCard product={p} onDelete={handleDelete} />               // ПРАВИЛЬНО: p из состояния, handleDelete из useCallback
```

### 15. value без onChange

```jsx
<input value={dish} />                                              // НЕПРАВИЛЬНО: поле не редактируется
<input value={dish} onChange={(e) => setDish(e.target.value)} />  // ПРАВИЛЬНО: управляемое поле
<input defaultValue="Молоко" />                                     // или неуправляемое поле с начальным значением
```
