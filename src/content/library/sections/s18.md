### Условия

1. **Лёгкое. QuantityLabel.** Напишите компонент с пропсами `quantity` (число) и `unit` (строка, по умолчанию `'шт.'`). Он показывает «2 шт.», а при нуле — «нет в наличии».
2. **Лёгкое. Найдите четыре ошибки** в коде ниже и исправьте их.
3. **Среднее. CategoryFilter.** Сделайте управляемый фильтр с пропсами `categories`, `selected` и `onSelect`. Родитель `FridgePage` хранит выбранную категорию и показывает только подходящие продукты. Кнопка «все» сбрасывает фильтр.
4. **Среднее. Подъём состояния.** Есть форма `AddProductForm` и список продуктов. После нажатия «Добавить» новый продукт появляется в списке, счётчик растёт, а поле очищается. Пустое название не добавляется.
5. **Сложное. TrickCounter для преферанса.** Пропсы: `tricks` — объект вида `{ Алексей: 4, Мария: 2, Бот: 1 }`, `declarer` — имя разыгрывающего, `contract` — заказанное число взяток. У разыгрывающего покажите «4 из 6, осталось взять 2» или «6 из 6, контракт выполнен».
6. **Сложное. Типы как защита секретов.** Опишите на TypeScript тип пропсов `OpponentSeat` так, чтобы компилятор не дал передать в компонент карты соперника.

### Ответ 1

```jsx
function QuantityLabel({ quantity, unit = 'шт.' }) {
  if (quantity === 0) return <span>нет в наличии</span>; // ранний return
  return <span>{quantity} {unit}</span>;
}
```

Проверка: `quantity={2}` дало «2 шт.», `quantity={0}` — «нет в наличии», `quantity={500} unit="г"` — «500 г». Сравнение `=== 0` точнее, чем `!quantity`: оно не перепутает ноль с непереданным пропом.

```jsx
// Управляемый фильтр: сам ничего не хранит
function CategoryFilter({ categories, selected, onSelect }) {
  return (
    <div className="filter">
      {['все', ...categories].map((c) => (
        <button key={c} aria-pressed={c === selected} onClick={() => onSelect(c)}>
          {c}
        </button>
      ))}
    </div>
  );
}

function FridgePage({ products }) {
  const [selected, setSelected] = useState('все');

  // оба значения производные — вычисляем, а не храним
  const categories = [...new Set(products.map((p) => p.category))];
  const visible = selected === 'все' ? products : products.filter((p) => p.category === selected);

  return (
    <>
      <CategoryFilter categories={categories} selected={selected} onSelect={setSelected} />
      <ul>{visible.map((p) => <li key={p.id}>{p.name}</li>)}</ul>
    </>
  );
}
```

### Ответ 4

```jsx
import { useState } from 'react';

// Форма хранит только набираемый текст, а список живёт у родителя
function AddProductForm({ onAdd }) {
  const [name, setName] = useState('');

  function handleSubmit(e) {
    e.preventDefault();
    if (!name.trim()) return; // пустое название не добавляем
    onAdd(name.trim());       // событие уходит наверх
    setName('');              // очищаем поле
  }

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={(e) => setName(e.target.value)} placeholder="Новый продукт" />
      <button>Добавить</button>
    </form>
  );
}

function Fridge() {
  const [items, setItems] = useState([{ id: 'milk', name: 'Молоко' }]);

  function handleAdd(name) {
    setItems((prev) => [...prev, { id: crypto.randomUUID(), name }]); // уникальный id для key
  }

  return (
    <>
      <AddProductForm onAdd={handleAdd} />
      <p>Продуктов: {items.length}</p>
      <ul>{items.map((p) => <li key={p.id}>{p.name}</li>)}</ul>
    </>
  );
}
```

Проверка: ввели «  Сыр » с пробелами — в списке появился «Сыр», счётчик показал 2. Ввод из одних пробелов ничего не добавил. `crypto.randomUUID()` создаёт случайный уникальный id. Он создаётся один раз при добавлении и потом не меняется, поэтому годится в роли `key`, в отличие от `Math.random()` внутри JSX.

### Ответ 5

```jsx
function TrickCounter({ tricks, declarer, contract }) {
  return (
    <ul className="tricks">
      {Object.entries(tricks).map(([player, count]) => {
        const isDeclarer = player === declarer;
        const left = contract - count; // сколько ещё нужно взять
        return (
          <li key={player} className={isDeclarer ? 'declarer' : undefined}>
            {player}: {count}
            {isDeclarer &&
              (left > 0 ? ` из ${contract}, осталось взять ${left}` : ` из ${contract}, контракт выполнен`)}
          </li>
        );
      })}
    </ul>
  );
}

<TrickCounter tricks={{ Алексей: 4, Мария: 2, Бот: 1 }} declarer="Алексей" contract={6} />
```

Проверка: при 4 взятках показано «Алексей: 4 из 6, осталось взять 2», при 6 — «Алексей: 6 из 6, контракт выполнен». `Object.entries` превращает объект в массив пар `[имя, число]`, а имя игрока уникально и подходит для `key`. `className={undefined}` React просто не выводит.
