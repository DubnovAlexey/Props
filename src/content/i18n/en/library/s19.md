All the terms of the document in one place, in alphabetical order. The last column gives the section where the term is covered in detail.

| Term | In simple words | Section |
| --- | --- | --- |
| Callback | A function handed over to be called later: “call me back” | 7 |
| camelCase | The words go together, each next one with a capital letter: `backgroundColor` | 9 |
| `children` | The prop with everything that stands between the tags of a component, the “filling” | 8 |
| Child component | The one used inside another component | 1 |
| Comparing by reference | “Is this the very same object?”, not “does it look similar?” | 10 |
| Component | A piece of the interface shaped as a function that returns markup | 1 |
| Component tree | A diagram of “who is inside whom”, like a family tree | 5 |
| Composition | Assembling an interface from nested components, like a construction set | 8 |
| Conditional rendering | Different markup depending on the data | 13 |
| Context | A way to pass a value to all descendants without props, a “loudspeaker” | 12 |
| Controlled component | The value comes in `value`, changes go out in `onChange`: the parent holds the wheel | 13 |
| `createContext` | Create a context with a default value | 12 |
| Default value | A fallback value for a prop that was not passed; works only for `undefined` | 4 |
| Dependency array | A list of values whose change makes a hook recompute the result | 10 |
| Derived value | A value that is not stored but computed from props or state | 6 |
| Descendant | Any component lower in the tree: a child, a “grandchild” and further | 5 |
| Destructuring | Unpack the fields of an object into separate variables | 4 |
| DOM | The real tags of the page in the browser | 2 |
| Event handler | A function that reacts to a click, typing or a form submission | 7 |
| Event prop | A function prop whose name starts with `on`, the channel from the child to the parent | 7 |
| Expression | Code that gives a value; only this can be written in `{ }` in JSX | 3 |
| `forwardRef` | The old wrapper for passing `ref`; no longer needed in React 19 | 9 |
| Fragment `<>…</>` | A wrapper that groups elements and adds no tag to the DOM | 8 |
| HOC | A function that takes a component and returns a new one with extra props | 13 |
| Hook | A special React function whose name starts with `use`, a “hook” to catch hold of its abilities | 6 |
| Immutability | Do not edit the original, create a new copy with the correction | 5 |
| JSDoc | Types in `/** … */` comments for ordinary JavaScript | 11 |
| JSX | “HTML inside JavaScript” that turns into function calls before running | 2 |
| `key` | The “ticket” of a list item; it does not get into the props | 9 |
| Lifting state up | Move shared data into the nearest common parent | 7 |
| `memo` | A “guard”: do not re-render a component if the props are the same | 10 |
| Memoisation | “We already computed it — take it from memory” | 10 |
| Mutation | Changing an existing object in place | 5 |
| One-way data flow | Data flows only from top to bottom, like water down the pipes | 5 |
| Parent component | The one that uses another component and passes it props | 1 |
| PascalCase | Every word with a capital letter, the first one included: `ProductCard` | 16 |
| Pattern | A proven “recipe” for a frequent task | 13 |
| Player view | The part of the game state one player is allowed to see | 15 |
| Portal | Show a component in a different place of the page than where it stands in the tree | 8 |
| Prop drilling | Dragging a prop through components that do not need it | 12 |
| PropTypes | The old type check while the program runs; removed in React 19 | 11 |
| Props | Data the parent passes to the child, like the arguments of a function | 1 |
| Provider | A “transmitter” component that sets the value of a context for everything inside | 12 |
| Pure function | The same input gives the same result, and nothing outside changes | 5 |
| React Compiler | A build tool that places memoisation by itself | 10 |
| React element | A description object `{ type, key, props }`: a note “what to draw and with what data” | 2 |
| ReactNode | Any content React can draw | 8, 11 |
| Reconciliation | Comparing “before and after” to change only the difference in the DOM | 2 |
| `ref` | A bookmark on a DOM node; in React 19 an ordinary prop of a function component | 9 |
| Re-render | Calling the component again with fresh data | 6 |
| Render | The moment React calls a component and learns what to show | 2 |
| Render prop | A function prop that tells a component what to draw | 13 |
| Rest `...rest` | “Everything else into this bag” during destructuring | 4 |
| Setter | A function like `setProducts`: save the new value and update the screen | 6 |
| Shallow comparison | Compare the props one by one without looking inside objects | 10 |
| Side effect | The function “did something else” besides returning a result | 5 |
| Single source of truth | Every value has one owner | 7 |
| Slot | A labelled place in a component for someone else’s markup | 8 |
| Spread `{...obj}` | Lay an object out into separate props | 3 |
| State | The memory of a component, which it changes itself | 6 |
| Statement | A command without a value, like `if` or `for`; not allowed in `{ }` in JSX | 3 |
| Static checking | Finding mistakes in the text of a program, without running it | 11 |
| StrictMode | A checking mode: in development it calls components twice to catch impure code | 5 |
| Transpilation | An automatic translation of JSX into ordinary JavaScript | 2 |
| TypeScript | JavaScript with types and a check before running | 11 |
| Uncontrolled component | Keeps its value itself, the parent sets only the initial one | 13 |
| Updater function | `setX((prev) => …)`: React itself passes the current value | 10 |
| `use` | A new way to read a context in React 19, works like `useContext` | 12 |
| `useCallback` | A hook: do not create a function anew without a reason | 10 |
| `useContext` | A “receiver” hook: read the nearest value of a context | 12 |
| `useMemo` | A hook: remember the result of a calculation between renders | 10 |
| `useState` | A hook: “give me a memory cell and a button to change it” | 6 |
| Virtual DOM | A draft of the page made of React elements in memory | 2 |
| Wrapper | A “frame” component around someone else’s content | 8 |
