### Ten rules in one line each

1. Props are the only argument of a component, one object.
2. A string literal goes in quotes, any JavaScript expression (a string included) goes in curly braces.
3. Data flows down, events go up through functions.
4. Props are only read, and changes are made by the owner of the data.
5. Compute values from props during render instead of copying them into state.
6. Pass the function, not the result of calling it.
7. A list item needs a stable `key`, and it does not get into the props.
8. `children` is an ordinary prop with the content between the tags.
9. React compares objects and functions by reference.
10. Props and composition first, and only then Context.
