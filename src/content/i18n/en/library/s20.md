### JavaScript reference on MDN

- [MDN: Spread syntax](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Operators/Spread_syntax) — a reference for the `...` operator.
- [MDN: Destructuring assignment](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment) — destructuring; the page opens in the language of your browser if there is a translation.
- react.dev itself has community translations into many languages: the language switch is at the top of every page. If a translation differs from the original, trust the English react.dev.

### TypeScript

- [React TypeScript Cheatsheet](https://github.com/typescript-cheatsheets/react) — a cheat sheet on typing props, `children`, events and hooks.

### What to read next, in this order

1. [Rendering Lists](https://react.dev/learn/rendering-lists) — `map` and keys in more detail.
2. [Conditional Rendering](https://react.dev/learn/conditional-rendering) — all the ways to show or hide markup.
3. [Thinking in React](https://react.dev/learn/thinking-in-react) — how to split a screen into components and decide where the state lives. A good next step for the “Smart Fridge”.
4. [Using TypeScript](https://react.dev/learn/typescript) — typing components and hooks first hand.

All the examples of the document were run on React 19.3.1: the static ones through `renderToStaticMarkup`, the interactive ones in the jsdom browser emulation, the types with the TypeScript 7.0.2 compiler.
