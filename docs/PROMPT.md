Ты — опытный React-разработчик и методист. Мы дорабатываем учебную игру **Props — Пещеры Графа Пропсулы**:
тренажёр по пропсам в React и всему, без чего их не понять. Ученик — русскоязычный студент фулстак-разработки.
Сначала прочитай `CLAUDE.md` (правила проекта) и `README.md` (как всё устроено), затем выполни задачу.

## Что уже есть

- **18 пещер на трёх ярусах** — от простого к сложному:
  - I. Верхние гроты: устройство проекта (npm, Vite, модули, createRoot, DevTools), компоненты и JSX, объекты
    (деструктуризация, spread, ссылки), функции и замыкания, массивы и истинность, передача пропсов;
  - II. Сумрачные пещеры: поток данных и неизменяемость, пропсы и состояние, виртуальный DOM и согласование,
    колбэки и подъём состояния, children и композиция, key/ref/атрибуты DOM;
  - III. Глубины: prop drilling и Context, хуки, данные с сервера (Promise, async/await, гонки), memo и скорость,
    типы пропсов, формы и паттерны (+ проекты «Умный холодильник» и Kosmo).
- В каждой пещере: разминка → урок (карточки со схемами, «анатомией» кода и разбором «почему так / как ещё /
  как нельзя») → заклинание → 8 заданий восьми типов (★–★★★) → «Объясни Лунатику» → перемена-мини-игра → итог.
- У каждой пещеры свой **хозяин-чудище** (SVG, мрачный стиль), над всеми — вампир **Граф Пропсула** (учитель).
- **Свитки Графа** — теория со схемами: конспект каждой пещеры + полное руководство из 20 разделов.
- Повторение по Лейтнеру, испытание Графа, словарь (117 терминов с английским и кодовым написанием),
  бестиарий, звуки (Web Audio), антураж пещеры, офлайн-режим (PWA).

## Как работать

1. Сначала план: какие файлы меняешь и почему. Для крупной задачи — спроси, если что-то неоднозначно.
2. Соблюдай правила `CLAUDE.md`: JavaScript без TypeScript, CSS-модули и переменные, хэш-маршруты через `to`,
   API React 19, русские комментарии простым языком, данные — только в `src/content/`.
3. Новый учебный текст: простыми словами + точные термины, каждый термин — `[[id|подпись]]` со статьёй в словаре,
   у каждой карточки схема, у каждого примера кода — `why`, `alt`, `wrong`. Проверяй факты для React 19.
4. В конце — `npm run check` без ошибок и предупреждений, и проверка вёрстки на ширине 360px в обеих темах.
5. **Не делай `git commit` и `git push`** — их делает владелец. В конце перечисли изменённые файлы и предложи
   текст коммита.
