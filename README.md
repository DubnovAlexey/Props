# Props — Пещеры Графа Пропсулы 🦇

Игра-тренажёр по **пропсам в React** и всему, без чего их не понять. Спускаешься по 18 пещерам — от устройства
проекта до паттернов, — в каждой побеждаешь злобного хозяина-чудище, а учит тебя вампир **Граф Пропсула**.

| Что внутри                                                                | Сколько                                        |
| ------------------------------------------------------------------------- | ---------------------------------------------- |
| Пещеры (темы) на трёх ярусах                                              | 18 + логово Графа (итоговое испытание)         |
| Карточки урока — все со схемами или иллюстрациями                         | 103                                            |
| Примеры кода с «анатомией» и разбором «почему так / как ещё / как нельзя» | 95 (115 вариантов «как ещё», 141 «как нельзя») |
| Задания восьми типов, сложность ★ → ★★★                                   | 144                                            |
| Термины словаря с английским и кодовым написанием                         | 117                                            |
| Хозяева пещер (бестиарий)                                                 | 18 + Граф                                      |
| Свитки теории: конспекты пещер + полное руководство                       | 18 + 20 разделов                               |

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
```

Нужен Node.js 20.19+ или 22.12+. Подробно про IntelliJ IDEA и Claude Code — в [docs/INTELLIJ.md](docs/INTELLIJ.md),
готовый промпт для доработки — в [docs/PROMPT.md](docs/PROMPT.md). Всё о проекте в одном файле — пожелания,
устройство, идеи по развитию и история создания — в [HANDOFF.md](HANDOFF.md).

## Команды

| Команда           | Что делает                                           |
| ----------------- | ---------------------------------------------------- |
| `npm run dev`     | сервер разработки, изменения видны сразу             |
| `npm test`        | тесты: целостность контента и логика (345+ проверок) |
| `npm run lint`    | ESLint: ошибки и правила хуков                       |
| `npm run format`  | Prettier: единый стиль кода                          |
| `npm run build`   | сборка в `dist/` (+ `sw.js` для офлайна)             |
| `npm run preview` | посмотреть сборку как на GitHub Pages                |
| `npm run check`   | lint + тесты + сборка — перед каждым коммитом        |
| `npm run library` | пересобрать «Свитки Графа» из `docs/guide.md`        |

## Как устроена учёба

Каждая пещера — это шаги: **разминка** (угадай до урока) → **урок** (карточки со схемами, анатомией кода,
терминами с настоящим написанием) → **заклинание** (рифма-запоминалка) → **практика** (8 заданий от ★ к ★★★) →
**«Объясни Лунатику»** (своими словами) → **перемена** (мини-игра) → **итог** (хозяин пещеры повержен).

Ярусы идут от простого к сложному:

1. **Верхние гроты** — устройство проекта, компоненты и JSX, объекты, функции и замыкания, массивы, передача пропсов.
2. **Сумрачные пещеры** — поток данных, состояние, виртуальный DOM, колбэки, children, key и ref.
3. **Глубины** — Context, хуки, данные с сервера, memo и скорость, типы, формы и паттерны.

Приёмы запоминания (активное вспоминание, интервальное повторение, чередование, двойное кодирование,
дворец памяти, эффект необычного, эмоциональная окраска и другие) описаны в игре на странице «Методика».

## Как добавить пещеру

1. `src/content/chapters/NN-имя.js` — по образцу соседних (4–6 карточек, 8 заданий).
2. `NN-имя.syntax.js` — схема для каждой карточки, `why` / `alt` / `wrong` для каждого примера кода.
3. Строки в `chapters/index.js`, `difficulty.js`, `story.js` (сюжет и хозяин), портрет в `src/mascot/guardians/`.
4. Новые термины — в `glossary.js` и `glossaryCode.js`.
5. `npm run check` — тесты подскажут, что забыто.

## Публикация и офлайн

Пуш в ветку `main` запускает GitHub Actions: тесты → сборка → GitHub Pages (в репозитории:
**Settings → Pages → Source: GitHub Actions**). С адреса Pages игру можно установить на телефон или компьютер —
она работает без интернета (сервис-воркер кэширует все файлы). Внутри предпросмотра claude.ai установка и офлайн
недоступны: браузер запрещает сервис-воркеры во встроенных окнах.
